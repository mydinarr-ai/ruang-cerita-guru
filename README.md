# Ruang Cerita Guru

Alat gratis untuk guru: membuat ide cerita, storyboard, karakter, dan prompt video pembelajaran dengan AI (untuk Google Flow / Omni).

Dikembangkan oleh Tim Digitalisasi Guru SMK Negeri 1 Yogyakarta. Desain oleh Dina Ratnasari Heryani, S.E.

## Cara pakai
1. Buka halaman web ini.
2. Isi kunci AI gratis dari https://aistudio.google.com/apikey (sekali saja; disimpan hanya di browser Anda).
3. Ikuti 5 langkah: Ide, Storyboard, Karakter, Prompt, Unduh.
